# 동현초™ · donghyun-lab1

동현랭은 난해한 프로그래밍 언어로 동현초의 초파리는 동현랭만 알아듣는다. 예제를 골라 실행하고, 먹이와 장애물을 만나며 달라지는 이동과 신경 출력을 관찰하는 독립 초파리 회로실험실이다.

이 작은 초파리에는 공개된 실제 뇌 연결망에서 골라낸 **1,758개 뉴런과 121,135개의 방향성 연결**이 들어 있다. 동현초는 FlyWire의 공개 연결망과 Shiu 등의 공개 계산 모델을 바탕으로, 실험할 회로를 직접 추출하고 동현랭으로 자극·관찰할 수 있게 만든 프로젝트다.

- **[동현초 플레이그라운드 · 바로 실행하기](https://raspberry-kim.github.io/donghyun-lab1/)**: 초파리 실험실을 열고 예제를 실행해 보자.
- **[동현랭 플레이그라운드 · 언어 알아보기](https://raspberry-kim.github.io/donghyun-lang/)**: 동현초가 알아듣는 동현랭의 문법과 예제를 살펴보자.

## 13만여 뉴런의 공개 뇌에서, 이 초파리의 회로를 꺼냈다

출발점은 FlyWire v783 연결 자료를 사용하는 **138,639개 뉴런의 원본 모델**이다. 동현초에서는 그 전체를 그대로 실행하는 대신, 단맛·쓴맛·좌우 시각 자극을 실험할 회로를 골라 이 작은 몸에 연결했다. 화면 속 캐릭터 뒤에는 실제 뉴런 ID와 원자료의 연결값이 남아 있다.

- **반응을 보고 골랐다:** 단맛, 단맛과 쓴맛의 혼합, 좌우 LPLC2 시각 뉴런 자극 등 여섯 조건의 사전 계산에서 발화한 뉴런을 모았다. 여기에 자극을 넣는 감각 뉴런과 결과를 읽을 관측 뉴런을 포함해 1,758개를 남겼다.
- **원래 배선을 보존했다:** 선별된 뉴런끼리 이어지는 방향성 연결 121,135개를 함께 추출했다. 연결을 임의로 새로 그린 것이 아니라, 원자료의 뉴런 ID와 부호 있는 연결값을 보존하고 모든 내보낸 연결을 원본과 대조했다.
- **브라우저에서 실험하게 만들었다:** 뇌 전체가 아니라 선택한 회로에 계산을 집중해, 서버 없이 실행할 수 있는 단일 HTML에 담았다. 사용자는 동현랭으로 자극을 넣고 신경 출력을 읽으며, 그 신호와 연결된 초파리의 반응을 관찰할 수 있다.

공개 연결망을 만든 공은 FlyWire와 원 연구진에게 있다. 동현초의 작업은 그 자료에서 실험용 회로를 선별·추출하고, 계산기와 몸체를 연결해 동현랭으로 다룰 수 있는 실험실로 만든 것이다. 선별 기준과 원자료 대조 기록은 [PROVENANCE.md](PROVENANCE.md)에 공개했다.

## 시작하기

파일을 내려받거나 프로그램을 설치할 필요 없이 웹에서 시작할 수 있다. 동현랭을 처음 접해도 준비된 예제를 선택해 실행하면 된다.

1. **[동현초 플레이그라운드 열기](https://raspberry-kim.github.io/donghyun-lab1/)**를 누른다.
2. 예제를 선택한다. 처음에는 **01 · 설탕을 만난 산책**을 권장한다.
3. **코드 실행**을 누르고 초파리가 걷다가 먹이를 만났을 때의 반응을 관찰한다. macOS에서는 Command+Enter, Windows/Linux에서는 Ctrl+Enter로도 실행할 수 있다.
4. 이동 궤적과 발화율·기록을 살펴본다. 실행을 멈추려면 **오겡끼데스까**를 누른다.
5. 다른 예제를 실행하거나 코드를 바꿔 나만의 실험을 만든다. 코드는 `.dh` 파일로, 관측 결과는 CSV로 저장할 수 있다.

예제를 고르는 것만으로는 실험이 진행되지 않는다. **코드 실행**을 누를 때마다 새 실험으로 시작한다.

회로의 원리와 근거가 궁금하면 **모델과 출처** 탭을 연다. 그 안의 **모델 설명·데이터 계보·전체 출처·이용 안내·글꼴·코드 라이선스** 메뉴에서 기존 설명과 원문 고지를 모두 읽을 수 있다. 데이터 계보와 출처 문서는 제목·굵은 글씨·표·링크가 적용된 문서로 표시된다.

## 실제 연결망과 계산 모델

1,758개는 모든 기능을 대표하는 무작위 표본이나 뇌 전체의 축소 복제품이 아니라, 선택한 실험 조건을 중심으로 추린 부분 회로다. 121,135개는 방향성 뉴런 쌍 연결 수이며 개별 시냅스 총수가 아니다. 실제 연결 자료에 계산 모델을 적용한 결과이지, 살아 있는 초파리에서 실시간 측정한 신경 활동이나 완전한 생물 복제가 아니다.

기반 자료는 [FlyWire](https://flywire.ai/guidelines), 계산법은 [Shiu 등의 모델](https://www.nature.com/articles/s41586-024-07763-9)을 사용한다. 걷기·충돌 처리·신경 출력과 몸체 동작의 연결은 별도 규칙이며, 냄새 추적·비행·보상 학습은 재현하지 않는다. 도파민성 8뉴런 자극은 단순 모델의 자극 실험이고, 행복이나 학습을 뜻하지 않는다.

## 인터넷 없이 사용하기

오프라인에서도 사용하고 싶다면 저장소의 `index.html`을 내려받아 브라우저로 연다. 코드, 회로 데이터, 글꼴, 예제와 출처·라이선스가 한 파일에 들어 있어 별도 설치나 서버 없이 실행할 수 있다.

일부 모바일 파일 미리보기에서는 스크립트가 실행되지 않을 수 있다. 그런 경우에는 인터넷에 연결한 뒤 [동현초 플레이그라운드](https://raspberry-kim.github.io/donghyun-lab1/)를 브라우저에서 연다. 외부 문헌이나 동현랭 사이트를 여는 데에는 인터넷이 필요하다.

## 파일 구성과 수정

```text
index.html           완성된 단일 HTML, GitHub Pages 진입점
README.md            소개와 사용법
GITHUB-SETUP.md       저장소 생성부터 웹 게시까지
SPEC.md              실험 입출력 어댑터 규약
LICENSE              코드·데이터·글꼴의 라이선스 구분
CREDITS.md           연구·기여자·이용 조건
PROVENANCE.md        데이터 계보와 모델 한계
CHANGELOG.md         변경 이력
src/                 분리된 HTML·CSS·실행기·계산 코드
data/connectome.json 축소 회로 데이터
fonts/               내장 글꼴
licenses/            원 라이선스 고지
examples/            11개 동현랭 프로그램
qa/                  자동 시험과 결과
build.cjs            별도 패키지 설치가 필요 없는 빌드
render-docs.cjs      문서의 HTML 변환과 앱 통합
vendor/              빌드용 Marked와 보존 정보
package.json         빌드·시험 명령
```

웹에서 실험만 할 때에는 아래 개발 작업이 필요 없다. 직접 코드를 수정하려면 Node.js 18 이상에서 다음 명령을 실행한다. 빌드에 쓰는 문서 변환 도구도 저장소에 포함되어 있으므로 `npm install`은 필요 없다.

```sh
npm test
npm run build
```

`src/`, `data/`, `fonts/`, 고지 문서를 수정한 뒤 빌드하면 루트 `index.html`, `동현초-v0.3.html`, 분리 파일 웹판 `dist/`, `examples/*.dh`가 생성된다. `PROVENANCE.md`, `CREDITS.md`, `licenses/`의 내용도 빌드 때 앱의 ‘모델과 출처’ 안에 서식 있는 문서로 포함된다. 원본은 `src/`와 이 문서들이므로 생성된 `index.html`만 수정하면 다음 빌드에서 덮어써진다. GitHub Pages에서는 루트 `index.html`만 갱신해도 새 완성본이 반영되지만, 소스와 문서도 함께 갱신하는 것을 권장한다.

자신의 저장소로 복사해 웹에 게시하려면 [GITHUB-SETUP.md](GITHUB-SETUP.md)를 참고한다. 이 안내는 개발·게시를 위한 것이며, 기존 동현초 플레이그라운드 이용에는 필요 없다.

## 이용 조건

**저장소 전체를 제한 없는 MIT 데이터로 취급하지 말아야 한다.** 앱 코드, 원 모델 코드, 동현랭 실행기, FlyWire 자료, 글꼴에는 서로 다른 조건이 적용된다. [LICENSE](LICENSE), [CREDITS.md](CREDITS.md), [licenses](licenses)를 함께 보존해야 한다.

[FlyWire 공식 지침](https://flywire.ai/guidelines)은 CC BY-NC 4.0을, [v783 Zenodo 배포 기록](https://zenodo.org/records/10676866)은 CC BY 4.0을 표시한다. 이 앱은 공식 지침을 기준으로 비상업적 교육용으로 제공하며, 이 문서가 원자료에 이미 부여된 개별 허락을 변경하지는 않는다. 상업적 재사용은 적용 조건을 권리자에게 확인해야 한다.

동현초는 FlyWire의 공식 앱이나 인증·후원 프로젝트가 아니다. 과학적·임상적 의사결정에 사용하는 검증된 시뮬레이터가 아니며, 전체 출처와 한계는 앱의 ‘모델과 출처’에도 표시한다.

## 검사 범위

v0.3 회로·실행 자동 시험 39개는 회로 구조·재현성·자극 반응, 11개 예제, 두 장애물 접촉, 새 예제의 정지·재이동, 두 DA 자극 구간, 빈 대조, 중단·오류 처리를 검사한다. 문서 시험 10개는 문단·표·인용·라이선스 보존, 굵은 글씨 등 HTML 변환, 내부 문서 연결과 위험한 마크업 처리를 확인한다. 실제 생물에 대한 독립 검증이나 실제 아이폰 기기 시험을 뜻하지 않는다.
