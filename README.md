# 동현초™ · donghyun-lab1

동현랭은 난해한 프로그래밍 언어로 동현초의 초파리는 동현랭만 알아듣는다. 예제를 골라 실행하고, 먹이와 장애물을 만나며 달라지는 이동과 신경 출력을 관찰하는 독립 초파리 회로실험실이다.

동현랭 플레이그라운드: https://raspberry-kim.github.io/donghyun-lang/

## 시작하기

`index.html`을 내려받아 브라우저로 열면 된다. 코드, 회로 데이터, 글꼴, 예제가 모두 들어 있어 인터넷 없이 실행할 수 있으며 별도 설치나 서버가 필요 없다. 일부 모바일 파일 미리보기에서는 스크립트를 실행하지 않으므로, 그런 환경에서는 GitHub Pages로 게시한 사이트를 브라우저에서 연다.

웹 게시 방법은 [GITHUB-SETUP.md](GITHUB-SETUP.md)에 있다. 저장소 이름은 `donghyun-lab1`이고 GitHub Pages는 `main` 브랜치의 루트에서 제공하도록 구성한다.

1. 예제를 선택한다. 선택만으로 실험은 진행되지 않는다.
2. **코드 실행**을 누른다. macOS는 Command+Enter, Windows/Linux는 Ctrl+Enter도 된다.
3. 궤적·발화율·기록을 관찰한다. **오겡끼데스까**로 중단할 수 있다.
4. 코드는 `.dh`, 관측은 CSV로 저장한다. 새 실행은 새 실험으로 시작한다.

## 실제 연결망과 계산 모델

이 앱에는 FlyWire v783에서 추출한 뉴런 1,758개와 방향성 뉴런 쌍 연결 121,135개가 포함되어 있다. 실제 연결 자료에 계산 모델을 적용한 결과이지, 살아 있는 초파리에서 실시간 측정한 신경 활동이나 완전한 생물 복제가 아니다. 연결과 파라미터의 계보는 [PROVENANCE.md](PROVENANCE.md)에 기록했다.

기반 자료는 [FlyWire](https://flywire.ai/guidelines), 계산법은 [Shiu 등의 모델](https://www.nature.com/articles/s41586-024-07763-9)을 사용한다. 걷기·충돌 처리·신경 출력과 몸체 동작의 연결은 별도 규칙이며, 냄새 추적·비행·보상 학습은 재현하지 않는다. 도파민성 8뉴런 자극은 단순 모델의 자극 실험이고, 행복이나 학습을 뜻하지 않는다.

## 파일 구성과 수정

```text
index.html           완성된 단일 HTML, GitHub Pages 진입점
README.md            소개와 사용법
GITHUB-SETUP.md       저장소 생성부터 웹 게시까지
SPEC.md              실험 입출력 어댑터 규약
LICENSE              코드·데이터·글꼴의 라이선스 구분
CREDITS.md           연구·기여자·이용 조건
PROVENANCE.md        데이터 계보와 모델 한계
CHANGELOG.md         변경 이력
src/                 분리된 HTML·CSS·실행기·계산 코드
data/connectome.json 축소 회로 데이터
fonts/               내장 글꼴
licenses/            원 라이선스 고지
examples/            11개 동현랭 프로그램
qa/                  자동 시험과 결과
build.cjs            외부 패키지 없는 빌드
package.json         빌드·시험 명령
```

사용만 할 때에는 `index.html` 하나면 된다. 개발할 때는 Node.js 18 이상에서 다음 명령을 실행한다. 의존 패키지가 없으므로 `npm install`은 필요 없다.

```sh
npm test
npm run build
```

`src/`, `data/`, `fonts/`, 고지 문서를 수정한 뒤 빌드하면 루트 `index.html`, `동현초-v0.3.html`, 분리 파일 웹판 `dist/`, `examples/*.dh`가 생성된다. 원본은 `src/`이므로 생성된 `index.html`만 수정하면 다음 빌드에서 덮어써진다. GitHub Pages에서는 루트 `index.html`만 갱신해도 새 완성본이 반영되지만, 소스와 문서도 함께 갱신하는 것을 권장한다.

## 이용 조건

**저장소 전체를 제한 없는 MIT 데이터로 취급하지 말아야 한다.** 앱 코드, 원 모델 코드, 동현랭 실행기, FlyWire 자료, 글꼴에는 서로 다른 조건이 적용된다. [LICENSE](LICENSE), [CREDITS.md](CREDITS.md), [licenses](licenses)를 함께 보존해야 한다.

[FlyWire 공식 지침](https://flywire.ai/guidelines)은 CC BY-NC 4.0을, [v783 Zenodo 배포 기록](https://zenodo.org/records/10676866)은 CC BY 4.0을 표시한다. 이 앱은 공식 지침을 기준으로 비상업적 교육용으로 제공하며, 이 문서가 원자료에 이미 부여된 개별 허락을 변경하지는 않는다. 상업적 재사용은 적용 조건을 권리자에게 확인해야 한다.

동현초는 FlyWire의 공식 앱이나 인증·후원 프로젝트가 아니다. 과학적·임상적 의사결정에 사용하는 검증된 시뮬레이터가 아니며, 전체 출처와 한계는 앱의 ‘모델과 출처’에도 표시한다.
