# 동현초™ · donghyun-lab1

동현초의 작은 초파리는 동현랭만 알아듣는다. 동현랭은 한국어로 쓰는 난해한 프로그래밍 언어다. 예제를 골라 실행하면 초파리가 걷다가 설탕을 만나 멈추기도 하고, 쓴맛에 놀라 다시 걷기도 한다. 그 순간 뇌 회로에서 어떤 신호가 오가는지 함께 지켜볼 수 있다.

이 초파리 안에는 실제 공개 뇌 연결망에서 골라 온 **1,758개 뉴런과 121,135개의 방향성 연결**이 들어 있다. FlyWire가 공개한 연결망과 Shiu 등의 계산 모델을 바탕으로, 실험할 회로를 직접 골라내고 동현랭으로 자극하고 관찰할 수 있게 엮었다.

- **[동현초 플레이그라운드에서 바로 실행하기](https://raspberry-kim.github.io/donghyun-lab1/)**
- **[동현랭 플레이그라운드](https://raspberry-kim.github.io/donghyun-lang/)**: 초파리가 알아듣는 언어의 문법과 예제를 볼 수 있다.
- **[동현파™ · 선충 촉각 회로실험실](https://raspberry-kim.github.io/donghyun-lab2/)**: 같은 언어로 픽셀 소녀의 타격과 선충의 반응을 관찰하는 두 번째 실험실이다.
- **[동현빌™ · 마을 유행 실험실](https://raspberry-kim.github.io/donghyun-lab3/)**: 실제로 기록된 469명의 만남 위에서 홍역·백일해·인플루엔자의 유행과 접종을 실험하는 세 번째 실험실이다.

네 사이트는 상단의 **동현의 작은 실험들** 메뉴로 이어져 있다. 지금 보고 있는 곳은 노란색으로 표시된다.

## 13만여 뉴런의 뇌에서 이 초파리의 회로를 꺼내 왔다

출발점은 FlyWire v783 연결 자료를 쓰는 **138,639개 뉴런의 원본 모델**이다. 전체를 그대로 돌리기에는 브라우저가 감당하기 어려워서, 단맛과 쓴맛, 좌우 시각 자극을 실험하는 데 필요한 회로만 골라 초파리 몸에 연결했다. 초파리 그림 뒤에는 실제 뉴런 ID와 원자료의 연결값이 그대로 남아 있다.

- **반응을 보고 골랐다.** 단맛, 단맛과 쓴맛의 혼합, 좌우 LPLC2 시각 뉴런 자극 등 여섯 조건을 미리 계산해 보고, 그때 발화한 뉴런을 모았다. 여기에 자극을 넣을 감각 뉴런과 결과를 읽을 관측 뉴런을 더해 1,758개가 되었다.
- **원래 배선은 건드리지 않았다.** 고른 뉴런끼리 이어지는 방향성 연결 121,135개를 원자료에서 그대로 가져왔다. 연결을 새로 그려 넣지 않았고, 뉴런 ID와 부호 있는 연결값을 보존한 채 내보낸 연결을 모두 원본과 대조했다.
- **브라우저 한 장에 담았다.** 계산을 고른 회로에 집중한 덕분에 서버 없이 HTML 파일 하나로 실행된다. 동현랭으로 자극을 넣고 신경 출력을 읽으면서, 그 신호에 따라 움직이는 초파리를 볼 수 있다.

연결망을 만든 공은 FlyWire와 원 연구진에게 있다. 동현초가 한 일은 그 자료에서 실험용 회로를 골라 꺼내고, 계산기와 몸을 이어 동현랭으로 다룰 수 있는 실험실로 만든 것이다. 어떤 기준으로 골랐는지, 원자료와 어떻게 대조했는지는 [PROVENANCE.md](PROVENANCE.md)에 적어 두었다.

## 시작하기

설치할 것은 없다. 동현랭을 몰라도 준비된 예제를 고르고 실행해 보면 된다.

1. **[동현초 플레이그라운드](https://raspberry-kim.github.io/donghyun-lab1/)**를 연다.
2. 예제를 고른다. 처음이라면 **01 · 설탕을 만난 산책**이 좋다.
3. **실행**을 누르고, 초파리가 걷다가 먹이를 만났을 때 어떻게 하는지 지켜본다. macOS에서는 Command+Enter, Windows나 Linux에서는 Ctrl+Enter로도 실행된다.
4. 이동 궤적과 발화율, 기록을 살펴본다. 도중에 멈추고 싶으면 **오겡끼데스까**를 누르면 된다.
5. 다른 예제를 돌려 보거나 코드를 고쳐 나만의 실험을 만들어 보자. 코드는 `.dh` 파일로, 관측 결과는 CSV로 저장할 수 있다.

예제를 고르기만 해서는 아무 일도 일어나지 않는다. **실행**을 누를 때마다 새 실험이 처음부터 시작된다. 실행 옆의 **10회 반복** 버튼을 누르면 같은 코드를 열 번 이어서 실행한다. 두 번째 실행부터는 매번 새 시드를 쓰므로 우연에 따라 결과가 어떻게 달라지는지 볼 수 있다. 반복 중에 다시 누르면 남은 실행을 취소한다.

회로가 어떻게 돌아가는지 궁금하다면 **모델과 출처** 탭을 열어 보자. 모델 설명, 데이터 계보, 전체 출처, 이용 안내, 글꼴과 코드 라이선스를 모두 그 안에서 읽을 수 있다.

## 실제 연결망과 계산 모델

1,758개는 뇌 전체를 줄인 복제품이 아니라, 고른 실험 조건을 중심으로 추린 부분 회로다. 121,135개도 방향이 있는 뉴런 쌍의 수이고, 개별 시냅스를 모두 센 숫자는 아니다. 화면에 보이는 반응은 실제 연결 자료에 계산 모델을 돌린 결과다. 살아 있는 초파리에서 잰 신경 활동은 아니다.

연결망은 [FlyWire](https://flywire.ai/guidelines), 계산법은 [Shiu 등의 모델](https://www.nature.com/articles/s41586-024-07763-9)을 따른다. 걷기와 충돌, 신경 출력을 몸의 움직임으로 바꾸는 부분은 동현초가 따로 정한 규칙이다. 냄새 따라가기나 비행, 보상 학습은 들어 있지 않다. 도파민성 뉴런 8개를 자극하는 실험도 단순 모델 안의 자극일 뿐, 초파리가 행복해하거나 무언가를 배운다는 뜻은 아니다.

## 인터넷 없이 쓰기

저장소의 `index.html`을 내려받아 브라우저로 열면 오프라인에서도 그대로 실행된다. 코드와 회로 데이터, 글꼴, 예제, 출처와 라이선스가 모두 이 파일 하나에 들어 있다.

휴대폰의 파일 미리보기 기능에서는 스크립트가 돌지 않을 때가 있다. 그럴 때는 브라우저에서 [동현초 플레이그라운드](https://raspberry-kim.github.io/donghyun-lab1/)를 열면 된다. 외부 논문이나 동현랭 사이트로 가는 링크는 인터넷이 있어야 열린다.

## 직접 고쳐 보고 싶다면

웹에서 실험만 할 때는 이 부분을 건너뛰어도 된다.

```text
index.html           완성된 단일 HTML, GitHub Pages 진입점
README.md            지금 읽고 있는 소개
SPEC.md              동현랭 출력을 실험 명령으로 바꾸는 규약
LICENSE              코드·데이터·글꼴의 라이선스 구분
CREDITS.md           연구와 기여자, 이용 조건
PROVENANCE.md        데이터 계보와 모델의 한계
CHANGELOG.md         버전별 변경 내용
src/                 HTML·CSS·실행기·계산 코드
data/connectome.json 축소 회로 데이터
fonts/               내장 글꼴
licenses/            원 라이선스 전문
examples/            동현랭 예제 21개
qa/                  자동 시험과 결과
build.cjs            추가 설치 없이 돌아가는 빌드 스크립트
render-docs.cjs      문서를 HTML로 바꿔 앱에 넣는 도구
vendor/              빌드용 Marked와 원 고지
package.json         빌드·시험 명령
```

Node.js 18 이상에서 아래 명령을 실행하면 된다. 필요한 도구가 저장소에 들어 있어서 `npm install`은 하지 않아도 된다.

```sh
npm test
npm run build
```

`src/`, `data/`, `fonts/`나 문서를 고친 뒤 빌드하면 루트의 `index.html`, `동현초-v1.22.html`, 분리 파일판 `dist/`, `examples/*.dh`가 새로 만들어진다. `PROVENANCE.md`, `CREDITS.md`, `licenses/`의 내용도 이때 앱의 ‘모델과 출처’ 안으로 들어간다. 생성된 `index.html`을 직접 고치면 다음 빌드에서 덮어써지니, 원본인 `src/`와 문서를 고치는 편이 좋다.

## 이용 조건

**이 저장소 전체가 MIT인 것은 아니다.** 앱 코드, 원 모델 코드, 동현랭 실행기, FlyWire 자료, 글꼴에 각각 다른 조건이 붙어 있다. 복사하거나 다시 배포할 때는 [LICENSE](LICENSE), [CREDITS.md](CREDITS.md), [licenses](licenses)를 함께 남겨 주길 바란다.

[FlyWire 공식 지침](https://flywire.ai/guidelines)은 CC BY-NC 4.0을, [v783 Zenodo 배포 기록](https://zenodo.org/records/10676866)은 CC BY 4.0을 표시하고 있다. 동현초는 공식 지침을 따라 비상업적 교육용으로 제공한다. 이 문서가 원자료에 이미 붙어 있는 이용허락을 바꾸지는 않으며, 상업적으로 쓰려면 권리자에게 직접 조건을 확인해야 한다.

동현초는 FlyWire의 공식 앱이 아니고, FlyWire가 인증하거나 후원한 프로젝트도 아니다. 과학적·임상적 판단에 쓰도록 검증된 시뮬레이터도 아니다. 전체 출처와 한계는 앱의 ‘모델과 출처’에서도 볼 수 있다.

## 시험해 본 범위

자동 시험 63개를 통과했다. 회로와 실행 시험 53개는 회로 구조와 재현성, 자극 반응, 21개 예제와 새 예제 10개의 결과, 두 장애물 접촉, 멈췄다 다시 걷기, 두 도파민 자극 구간, 빈 대조, 중단과 오류 처리를 확인한다. 문서 시험 10개는 출처 문서와 라이선스가 앱 안에서 빠짐없이, 안전하게 표시되는지 확인한다. 실제 초파리와 비교한 독립 검증이나 실제 아이폰에서 해 본 시험은 아직 아니다. 자세한 내용은 [qa/TESTING.md](qa/TESTING.md)에 있다.

**FlyWire Connectome에 영감을 받은 백신학자**

인하대학교 의과대학 김동현 교수는 백신학·감염학을 공부하고 가르친다. 공개된 FlyWire 신경망의 일부를 사용하여 동현초를 개발하고 있다. 동현초는 난해한 프로그래밍 언어인 동현랭을 기반으로 한다.
