# 동현초 v0.4 검사 기록

검사일은 2026-10-23이며, 동현랭 v1.52 실행기를 포함한 v0.4 코드로 검사했다. 이 기록은 소프트웨어 동작 시험이지 생물학적 정확도 인증이 아니다.

## 자동 검사

`npm test`로 회로·실행 39개와 문서 10개 검사를 실행한다. 회로 검사는 축소 회로 구조, 시드 재현성, 무자극 상태, 10개 시드의 단맛·쓴맛·좌우 시각 자극, 11개 예제의 종단 실행, 중단·오류 처리를 포함한다.

문서 검사는 `qa/docs-tests.cjs`에서 수행한다. Markdown의 모든 블록이 HTML 변환 후에도 남는지, 원 라이선스 텍스트가 보존되는지, 제목·굵은 글씨·표·코드·링크가 실제 요소로 생성되는지, 내부 문서 링크가 패널을 가리키는지, 원시 HTML과 위험한 URL이 실행되지 않는지를 확인한다.

추가된 검사에서는 03번 두 장애물 각각의 충돌과 비관통, 08번 정지·재출발·재정지, 09번 분리된 두 DA 자극 구간, 10번 쓴맛 출력 차단·복원, 11번 1초 무이동·무발화를 확인했다. `core-results.json`에 실험별 시간·거리·접촉 횟수와 회로 해시가 있다.

`data-results.json`은 이전 원본 v783 대조의 보존 기록이다. v0.4에서는 회로 데이터를 변경하지 않았다. 원본 대용량 parquet와 추출 작업 환경을 이 배포 묶음에 포함하지 않으므로 `npm test`는 원자료를 다시 내려받아 검증하지 않는다.

## 브라우저 검사

Chromium에서 11개 예제를 실제 선택·실행해 완료 상태를 확인했다. 실행 오류, 중단 후 재실행, 키보드 실행, 코드 저장·열기, CSV 다운로드, 세 탭과 동현랭 외부 링크를 확인했고 페이지 JavaScript 오류는 발생하지 않았다.

1440px 데스크톱과 375px 모바일 크기에서 밝은·어두운 화면, 설탕·쓴맛 혼합 먹이·장애물 그림을 검사했다. 모바일 크기에서 문서의 가로 넘침은 없었다. 모바일 크기 에뮬레이션은 실제 아이폰 기기 시험을 대신하지 않는다.

v0.4에서는 초파리 그림 배율을 1.18에서 0.94로 줄인 상태의 눈·날개·다리·섭식 표시와 모델 설명 끝의 제작자 소개를 검사했다. 화면·CSV·명세·데이터 계보·빌드 파일명의 버전 표기를 맞췄다. 회로 엔진·워커·예제·연결 데이터는 v0.3과 동일하다.

루트 `index.html`을 `file://`로 열고 브라우저 네트워크를 차단한 상태에서 03번 장애물 실험과 11번 빈 대조, 내장 출처를 확인했다. 문서 통합 후에는 ‘모델과 출처’의 하위 메뉴와 서식, 기존 해시 주소, 내부 링크·라이선스 펼침, 모바일 표 스크롤을 재검사했다. 외부 문헌과 동현랭 사이트를 여는 동작에는 인터넷이 필요하다.

## 빌드 재현성

배포 묶음의 파일만으로 `npm test`와 `npm run build`를 실행했다. 생성된 루트 `index.html`이 제공한 완성본과 바이트 단위로 같음을 비교했다. 빌드는 외부 패키지를 설치하지 않는다.

모든 브라우저·운영체제에 대한 호환성, 전뇌 모델과 모든 개입의 일치, 실제 동물 행동과의 일치는 이번 검사 범위가 아니다.
