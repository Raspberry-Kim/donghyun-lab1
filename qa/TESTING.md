# 동현초 v1.19 검사 기록

검사일은 2026-10-26이며, 동현랭 v1.53 실행기를 포함한 v1.19 코드로 검사했다. 이 기록은 소프트웨어 동작 시험이지 생물학적 정확도 인증이 아니다.

## 자동 검사

`npm test`로 회로·실행 52개와 문서 10개 검사를 실행한다. 회로 검사는 축소 회로 구조, 시드 재현성, 무자극 상태, 10개 시드의 단맛·쓴맛·좌우 시각 자극, 21개 예제의 종단 실행, 중단·오류 처리를 포함한다.

문서 검사는 `qa/docs-tests.cjs`에서 수행한다. Markdown의 모든 블록이 HTML 변환 후에도 남는지, 원 라이선스 텍스트가 보존되는지, 제목·굵은 글씨·표·코드·링크가 실제 요소로 생성되는지, 내부 문서 링크가 패널을 가리키는지, 원시 HTML과 위험한 URL이 실행되지 않는지를 확인한다.

추가된 검사에서는 11번 두 장애물 각각의 충돌과 비관통, 03번 정지·재출발·재정지, 14번 분리된 두 DA 자극 구간, 04번 쓴맛 출력 차단·복원, 21번 빈 코드의 무이동·무발화를 확인한다. 18번 거리 800 초과, 07번 설탕 네 덩이 접촉, 06번 설탕 다섯 덩이 접촉과 마지막 정지, 10번 거대섬유 100 Hz 초과, 19번 벽 접촉 3번 이하, 05번 미끼 세 개 섭식, 20번 충돌 없는 두 바퀴도 함께 확인한다. v0.6에서는 예제 21개가 하나씩 빠짐없이 번호 순서대로 놓이고 빈 실험이 맨 끝인지도 확인한다. v0.5에서 더한 예제 10개는 보행 속도를 1.2배로 올린 뒤에도 시드 1–8에서 따로 돌려 같은 결과가 나오는지 확인한다. `core-results.json`에 실험별 시간·거리·접촉 횟수와 회로 해시가 있다.

`data-results.json`은 이전 원본 v783 대조의 보존 기록이다. v0.4부터 v0.6까지 회로 데이터를 변경하지 않았다. 원본 대용량 parquet와 추출 작업 환경을 이 배포 묶음에 포함하지 않으므로 `npm test`는 원자료를 다시 내려받아 검증하지 않는다.

## 브라우저 검사

Chromium에서 11개 예제를 실제 선택·실행해 완료 상태 확인. v0.6에서는 예제 21개를 모두 다시 실행해 완료되었고, 이동 거리가 자동 시험과 일치했다. 픽셀아트 초파리는 밝은·어두운 화면, 걷기·섭식 모습을 확대 확인. v0.7에서는 날씬해진 몸, 둥근 붉은 머리, 가슴에 붙은 날개, 단맛을 먹을 때의 줄무늬 빨대를 같은 방식으로 확인. v0.8에서는 새로 그린 작은 머리와 양옆의 붉은 눈, 물방울 날개를 밝은·어두운 화면에서 다시 확인. v0.9에서는 동그란 만화 날개와 튀어나온 붉은 눈을 같은 방식으로 확인. 실행 오류, 중단 후 재실행, 키보드 실행, 코드 저장·열기, CSV 다운로드, 세 탭과 동현랭 외부 링크 확인. 페이지 JavaScript 오류는 발생하지 않았다.

1440px 데스크톱과 375px 모바일 크기에서 밝은·어두운 화면, 설탕·쓴맛 혼합 먹이·장애물 그림 검사. 모바일 크기에서 문서의 가로 넘침은 없었다. 모바일 크기 에뮬레이션은 실제 아이폰 기기 시험을 대신하지 않는다.

v0.4에서는 초파리 그림 배율을 1.18에서 0.94로 줄인 상태의 눈·날개·다리·섭식 표시와 모델 설명 끝의 제작자 소개 검사. 화면·CSV·명세·데이터 계보·빌드 파일명의 버전 표기 일치. 회로 엔진·워커·예제·연결 데이터는 v0.3과 동일하다.

루트 `index.html`을 `file://`로 열고 브라우저 네트워크를 차단한 상태에서 11번 장애물 실험과 21번 빈 실험, 내장 출처 확인. 문서 통합 후에는 ‘모델과 출처’의 하위 메뉴와 서식, 기존 해시 주소, 내부 링크·라이선스 펼침, 모바일 표 스크롤 재검사. 외부 문헌과 동현랭 사이트를 여는 동작에는 인터넷이 필요하다.

## 빌드 재현성

배포 묶음의 파일만으로 `npm test`와 `npm run build` 실행. 생성된 루트 `index.html`이 제공한 완성본과 바이트 단위로 동일함 확인. 빌드는 외부 패키지를 설치하지 않는다.

모든 브라우저·운영체제에 대한 호환성, 전뇌 모델과 모든 개입의 일치, 실제 동물 행동과의 일치는 이번 검사 범위가 아니다.
